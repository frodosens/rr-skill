# 建模与材质方法

## 截面放样

沿前后方向 Z 布置少数关键截面，每个截面记录半宽、底高、肩高/顶高。环内保留宽侧面、腰线窄斜面、顶部与底部。相邻截面连接成 quad，再拆为三角形；前后端盖闭合。只在轮拱、前脸转折和后宽肩处增加截面密度。

蓝车实现可直接阅读 `_width(z)`、`_arch_bottom(z)`、`_belt_height(z)`、`_body_shell()`：轮拱底线按轮心与半径计算上半圆，车身从该线向上形成真实开口，窄回折面提供厚度。不要用黑色贴片假冒洞口，或为消除穿插把轮胎内缩到错误接地点。

每个三角先由实际顶点求叉积法线，按外侧提示纠正法线方向，再按目标网格格式纠正绕序。非共面的 quad 分三角求各自法线，不强塞一个不对应表面的法线。Godot `_polygon` 的交换 b/c 逻辑和 glTF 导出的 CCW 逻辑要分别测试。

## 小面承担光照，大面承担识别

先做引擎盖、车门、车顶、后肩的大平面。倒角宽度受组件尺寸限制，不能把所有边都圆滑成高面数车。斜面玻璃与车柱的端点相互贴合，头灯嵌入前脸，不悬在机盖上。轮胎、轮圈、保险杠、牌照在正常游戏镜头下应清楚而不过曝。

宽体车型用前后不相同的外扩曲线与轮拱轮廓表达，保留原始轮心。需要改轮距、轴距、悬挂或碰撞时，明确转为物理变更并单独验收。

## 项目色板起点

以下是已有代码值，仅作同风格起点，不是物理测量值：

| 部分 | 示例 sRGB 色值 | metallic / roughness / specular |
| --- | --- | --- |
| 红车漆 | `6b100c` | 0 / 0.48 / 0.22 |
| 蓝车漆 | `0a318b` | 0.10 / 0.46 / 0.26 |
| 蓝车玻璃 | `213846` | 0 / 0.31 / 0.35 |
| 蓝车金轮毂 | `8d6c2e` | 0.55 / 0.43 / 0.38 |
| 深色橡胶 | `17232b` | 0 / 0.90 / 0.16 |
| 蓝车尾灯底色 | `992524` | 0 / 0.45 / 0.20 |

StandardMaterial3D 颜色直接用相应 Color 值；不要再手动 gamma 一遍。若改用顶点色或自定义 shader，核对该数据通道预期空间和导入管线，并在实际 Compatibility 渲染中比较。尾灯保持较暗红底与受控发光，由刹车改变能量；不以提高整体曝光来让车辆更亮。

## 合批与动画边界

静态部件按材料积累 SurfaceTool，完成一批后提交并清空。不要为每个螺丝独立建 MeshInstance。车轮仍需独立变换：玩家车用 pivot/Spinner，NPC 用共享轮网格的四实例 MultiMesh。动画数据在 CPU 保留可测镜像，设置高质量旋转插值避免物理 tick 间轮子缩放感。

普通材质共享，但不能在运行时修改共享 paint 导致其他车一起变色；选择已有资源绑定。刹车灯状态独立。没有理由时不增加纹理、透明层、车辆局部灯或反射探针。
