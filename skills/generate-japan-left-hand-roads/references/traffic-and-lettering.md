# 日本交通语义与路面文字

用于游戏制作，不是施工设计或法律意见。核查日期：2026-11-06。分别标记真实法规、地方要求、游戏设计与已实现行为；复现具体年代/地点时重新查对应官方资料。

## 标线选择

| 类型 | 生成原则 | 不应推断 |
| --- | --- | --- |
| 中央线 | 区分对向交通；由语义决定实/虚及颜色 | 不因日本风格统一涂黄 |
| 同向分界 | 只用于实际多个同向车道 | 不把双向中央线叫同向分界 |
| 外侧线 | 标明车行边缘，考虑路肩和接入 | 不自动等同有独立法律含义的路侧带 |
| 白虚线 | 按已核实布局设置；016只是视觉引导 | 不宣称任何时候都可超车 |
| 黄色中央实线 | 特定“追越しのための右側部分はみ出し通行禁止”控制需要来源 | 不笼统写成任何情形禁止跨线，或套用所有边线 |
| 停止线 | 绑定停车/信号控制及冲突区前的停止点 | 不给每个普通岔口自动添加 |
| 横断步道/菱形预告 | 由过街需求与明确规则决定 | 不为装饰随意放置 |
| 箭头 | 绑定方向和许可转向，区分建议与管制 | 不因几何可转就宣布允许 |

白实线效果需结合道路类别、宽度、标示及其他禁止地点，不统一解释为“随便越过”或“绝对不能越过”。先查官方表式和现场语义；缺依据时只做已批准视觉引导，不自动加入处罚或NPC强制动作。

016参数：边线0.15米，中心距车行边缘0.30米；中心虚线0.15米、3米线段/5米间隔、整路起点相位；路宽至少6米且明确双向左行才画其中心虚线。这是016范围控制，不是全国设置阈值。

## 词义与排版

| 表达 | 用途 | 避免 |
| --- | --- | --- |
| 止まれ / STOP | 明确一时停止，与停止位置对应 | 当作一般减速、停车位或等待区 |
| 徐行 / SLOW | 以能立即停车的速度通行 | 当作固定限速或国外三角让行牌同义词 |
| 減速 | 减速提醒，旧环路已烘焙 | 用简体“减速”；自动设置法定限速 |
| カーブ注意 | 弯道注意补充提示 | 未核对方向，首次提示藏在弯心/树后 |
| 転回場所 | 已验证私人掉头场地说明 | 宣称全国统一法定允许掉头牌 |
| 転回禁止 | 禁止掉头 | 用来标掉头区 |

先定义来车方向、停止线/冲突区和文字排布，再放牌。牌面朝来车，不朝固定世界轴。字可纵向拉长适应驾驶视角，必须保留字形。用驾驶方向正视、顶视与反向三个角度验收。

文字顶端远离司机，底端靠近司机；反向旋转180°保持非镜像。箭头尖端指向驾驶前方；沿弯箭头不可跨中央线形成U型掉头暗示。

用完整日文字体离线烘焙遮罩。旧字形源为Noto Sans CJK JP Bold；子集保留SIL OFL许可及必要重命名。检查实际遮罩中“減”的三点水，不能凭 `slow_ja.png` 文件名判断。共享图集、alpha scissor、mipmaps、各向异性过滤，避免每条路动态Label3D或运行时栅格化。

## 警告距离与速度

由曲率、遮挡和设计速度筛选候选，再按可见/可减速距离复核双向。半径小于60米、30米内方向变化大于20°只是规划筛选值，不是法定阈值。旧环路弯心前44米的文字仅是该场景参数，不复制到所有路。

区分法定/指定限速、推荐安全速度和NPC目标速度。雪天安全速度不等于晴天标牌上限。20/30/40km/h游戏分区未明确采用时保持proposed。

注意时效：东京官方资料说明自2026-09-01起，符合条件的生活道路汽车法定速度降至30km/h；有中央线/车道、方向隔离等例外，指定限速优先。不能因此给所有游戏住宅路涂“30”，也不能从一条装饰虚线自动改变游戏限速。
