# 制作 Godot 风格化驾驶场景

从可驾驶空间和真实地表出发，用离线资产、确定性分布和有界运行成本构建场景。美术画面、几何支撑、实际驾驶、流送和设备性能分别验收。

## 先读什么

- 找当前工程、历史阶段和复用入口：读 [项目来源与阶段](references/project-map.md)。
- 制作树石、建筑或选择 LOD：读 [离线资产制作](references/offline-assets.md)。
- 散布、接地、场景集成、天气：读 [PCG 与集成](references/pcg-integration.md)。
- 制作密集草丛、低矮植被或风动：读 [密集植被与 GPU 风动](references/dense-vegetation.md)。
- 开始运行测试或准备交付：读 [验收与性能](references/validation.md)。

## 1. 冻结本次范围

1. 找到权威 project.godot、默认入口、分块清单、现有车辆/HUD/玩法和最新验收记录。记录分支/commit、未提交差异和受保护文件。
2. 区分整图规划、独立风格样板、离线资产候选、局部主世界候选与已合入版本。不能因文件夹版本号更大就覆盖当前工程。
3. 记录授权改动的区域、资源类别、碰撞政策、画风目标、性能预算及回退点。默认保留原车、界面、任务、道路和存档。
4. 新场景方向先做小范围可驾驶样片；既有方向扩展则在真实世界坐标和分块上做隔离候选，不重造一张展示地图冒充集成。
5. 发布时按逐文件清单合入最新仓库，保留远端已有修改；不要用整个旧快照覆盖 main。

## 2. 把参考图变为制作规则

实际查看参考与当前引擎截图，提取：
- 近景/中景/远景层次、道路留白、视觉焦点、天际线与镜头高度；
- 暖草甸、冷森林、灰绿岩石、少量花色的色彩关系；
- 树冠轮廓、疏密节奏、林缘、岩石锚点、建筑体块与屋顶线；
- 材质细节密度、光照、薄雾、阴影对道路辨识的影响。

选定可执行的低多边形规则，不把概念图整张贴为背景或把纹理丰富度误当完成度。默认重用原资产并统一色板、大面、材质粗糙度和层次；其他游戏图片只作观察，不自动获得其资产授权。

## 3. 先空间，再资产，再分布

1. 从权威保存几何建立 surface catalog：资源 hash、类型、owner、实际三角形、坐标变换。地面与屋顶/水面分开。
2. 明确道路、路口、地块、建筑入口、停车区、湖岸/溪流、已有资产、安全设施和视线的保留域。
3. 资产先形成接口合同：米制尺寸、轴向/原点、LOD、材质、碰撞、入口锚点、天气通道、来源。
4. PCG 先树/岩石/建筑等实体，再草/花等细节；固定 seed、稳定排序与分层 RNG，保证新增石群不重排全部树。
5. 用连贯密度场、成簇林带、草甸空隙和种类/尺度变化构图，避免沿路等距排队或无差别铺满。
6. 采样完整足迹和最终模型底部，不只取中心高度。任何支撑缺失、来源 hash 不符、越界或超预算均硬失败，不降级为猜测高度。

## 4. 有界生成与运行

- 离线生成/烘焙几何与数值场，游戏加载静态资源；不要加入每树生长、逐帧散布或逐帧建网格。
- 根据空间 cell、材质、种类和 LOD 组织 MultiMesh，核验真实 AABB、实例变换和保存后的读回。过大的合批会破坏剔除。
- 后续密集草丛与适合面片表达的低矮植被，默认沿用已选的五片交叉草丛、固定根部的 GPU 顶点风动和分块 MultiMesh 方法；按 [密集植被与 GPU 风动](references/dense-vegetation.md) 接入真实地表、遮罩、LOD、雪与远景。不要把每丛动画放到 CPU，也不要将此方法强套到树木或需要实体体积的灌木。
- 一个世界管理器和明确 chunk owner。按现有合同裁切需要分属各块的表面；不能把相同道路碰撞复制到相邻 owner。
- 装饰是否阻车必须显式决定。旧山路树石无独立碰撞与新森林树干/石块有碰撞是不同方案，不能一概套用。
- 建筑由简单实体碰撞与门阶/通路合同接入，不能把屋顶误当道路支撑。资产默认禁用的碰撞不自动启用。
- 道路→泥土→草地过渡可由真实路面距离场和光照法线改善；视觉修改不移动顶点或偷偷改碰撞。若需改形，另走几何重验。
- 确认雪、LOD、材质和流送生命周期互相兼容。天气外观默认不改轮胎抓地、动力和悬挂。

## 5. 局部验证后扩展

先按 [验收与性能](references/validation.md) 完成来源/静态 → 原生保存读回 → 接地与碰撞 → 加卸载/晴雪 → 原车连续驾驶 → 实际画面 → 性能的分层检查。

保持失败日志和未通过项。到达终点不等于严格驾驶通过；当前源的 hash 不匹配时旧 PASS 无效。严格检查不要为消除告警而放宽阈值、瞬移、重置速度或关闭碰撞。

只有局部验收覆盖的内容才能扩大。输出变更清单、可重建输入、合同与 hashes、真实截图、执行结果、已知限制和回退方式。未测真机时不承诺手机 FPS；未核验新仓库状态时不宣布已合入 main。
